# Изображения разделов — ApertuRU VPN

Фирменные баннеры (3:1, 1280×427 PNG) для каждого экрана бота.
Стиль: диафрагма-апертура, бирюзовый `#3BC9DB` на глубоком чёрном.

## Структура

- `*.png` — готовые баннеры для загрузки через админку
- `svg/*.svg` — исходники баннеров (правь их, не PNG)
- `svg/icons/*.svg` — иконки Tabler Icons (outline), отрисованные в баннеры
- `generate.py` — генератор: `python3 menu_images/generate.py`

Перегенерация PNG из SVG (после правки исходников):

```bash
for f in menu_images/svg/*.svg; do
  name=$(basename "$f" .svg)
  rsvg-convert -w 1280 "$f" -o "menu_images/${name}.png"
done
```

## Как включить в боте

Изображения разделов загружаются через админ-панель бота:

**Админ → Управление изображениями разделов** → выбрать раздел → «Установить /
изменить» → отправить PNG как фото. Бот сохранит Telegram `file_id` и начнёт
показывать картинку в этом разделе.

Доступные разделы (20): главное меню, профиль, баланс, успешное пополнение,
мои подписки, активная подписка, промокод, поддержка, партнёрка, покупка
подписки, продление/апгрейд, активация подписки, информация, FAQ, правила,
конфиденциальность, публичная оферта, выбор языка, статус серверов,
пробный период.

Если у раздела картинка не задана — показывается `vpn_logo.png` (общий баннер).

## Главное меню / vpn_logo.png

`../vpn_logo.png` (3000×1000) — тот же бренд-баннер «APERTURU VPN».
Заменять файлом `rsvg-convert -w 3000 menu_images/svg/main_menu.svg -o vpn_logo.png`.
