# Изображения разделов — ApertuRU VPN

Фирменные баннеры (16:9, 1280×720 PNG) для экранов бота.
Стиль: диафрагма-апертура, бирюзовый `#3BC9DB` на глубоком чёрном.

## Структура (иерархия «раздел → подпункты»)

- `main_menu.png` — главное меню (плоский файл, отдельный макет)
- `vpn_logo.png` — общий логотип-заглушка (тот же макет, рендер 1920×1080)
- `<section>/_main.png` — главный баннер раздела (ключ БД `<section>`)
- `<section>/<sub>.png` — баннер подпункта (ключ БД `<section>.<sub>`)
- `svg/…` — SVG-исходники, зеркально той же структуре (`svg/<section>/_main.svg` и т.д.)
- `svg/icons/*.svg` — иконки Tabler Icons (outline), отрисованные в баннеры
- `generate.py` — генератор: `python3 menu_images/generate.py`
  (пишет SVG и сам рендерит все PNG через `rsvg-convert -w 1280`;
  `vpn_logo.png` рендерится из `main_menu.svg` шириной 1920)
- `MENU_MAP.md` — карта «экран бота → callback-паттерны → файл баннера»

Папки `subscription/` и `referral/` существуют только для подпунктов
(ключи `subscription.*`, `referral.*`); сами разделы называются
`my_subscriptions` и `referrals`. Всего 31 баннер-ключ:
19 разделов + `main_menu` + 11 подпунктов.

Перегенерация: просто запустите `generate.py` — отдельный рендер не нужен.

## Дизайн

- Главный баннер раздела (`_main`): чип с иконкой слева, крупный заголовок
  (авто-подбор размера, лимит ширины 1170px), бренд-строка
  «ApertuRU VPN — ПОДЗАГОЛОВОК».
- Баннер подпункта: тот же чип, но над заголовком — маленькая «плашка»
  с мини-иконкой раздела и подписью «РАЗДЕЛ ›» (например «БАЛАНС ›»),
  под ней крупный заголовок подпункта; бренд-строка без суффикса.
  Иерархия читается визуально: подпункт — крупно, раздел — мелко.
- Водяной знак-апертура справа внизу (230px), рамка, диагональная сетка.

## Как включить в боте

Изображения разделов загружаются через админ-панель бота:

**Админ → Настройки → 🖼️ Фото разделов** → выбрать раздел → «Установить /
изменить» → отправить PNG как фото. Бот сохранит Telegram `file_id` в
`system_settings` (ключ `ui_section_image.<ключ>`) и начнёт показывать
картинку в этом разделе.

Разделы (19 + главное меню): профиль, баланс, успешное пополнение, мои
подписки, активная подписка, промокод, поддержка, партнёрка, покупка
подписки, продление/апгрейд, активация подписки, информация, FAQ, правила,
конфиденциальность, публичная оферта, выбор языка, статус серверов,
пробный период.

Подпункты (11): баланс → история / карты / пополнение; подписки →
устройства / доп. трафик / автопродление / продление / перевыпуск;
партнёрка → список рефералов / аналитика / вывод средств.

Если у подпункта картинка не задана — берётся картинка раздела, затем
`vpn_logo.png` (общий баннер).

## vpn_logo.png

`vpn_logo.png` (1920×1080) — тот же бренд-баннер «ApertuRU VPN».
Заменять рендером `rsvg-convert -w 1920 svg/main_menu.svg -o vpn_logo.png`
(генератор делает это сам).
